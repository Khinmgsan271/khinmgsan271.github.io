# WalletScope WPF source — portfolio only

This C# .NET 8 WPF application demonstrates a searchable, filterable inventory table populated exclusively with synthetic records. The Windows-only code is not connected to the web app and has not been compiled on the author's Mac.

Run on Windows with the .NET 8 SDK:

    dotnet run --project WalletScope.Wpf/WalletScope.Wpf.csproj

The WPF variant includes CSV export with a native save dialog. No wallet discovery, software enumeration, browser extension inspection, network access or key access is implemented.

**Status:** original AI-assisted source prototype; not Windows-tested or delivered to any paying customer.
